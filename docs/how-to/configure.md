# Configure the harness

The settings window has a page per topic.
- Provider lists the adapters and the models each offers.
- Profiles keeps whole sets of settings and sign-ins apart, while every profile sees the same conversations.
- Theme, or F2 anywhere, changes the look.

On [harness-multitool.dev](https://harness-multitool.dev/docs/how-to/configure) this page plays it live (CON-187).

## In the real harness

- Tab changes pane, ↑↓ moves, Space or Enter selects, Ctrl+S saves, Esc closes.
- Ctrl+S on the Provider page moves every open conversation of the window onto the new choice, with its history.
- Profiles: Add, Edit, Delete and Use; or `multitool profile add work` and `multitool --profile work` for one run.
- F2 cycles the themes: dark, light, paper, sand, blossom, mist, nord, monokai, cyan.
